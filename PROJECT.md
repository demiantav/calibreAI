# Calibre - Autonomous Business Intelligence for Creators

## 1. Product Vision
Calibre is an autonomous AI Agent that manages the business side of content creation. It shifts the paradigm from **Manual Management** (reactive, fragmented) to **Autonomous Intelligence** (proactive, self-improving), acting as a "Digital Chief of Staff" for professional creators.

## 2. Target Users
- **Tier 1: Individual Creators:** Full-time creators (YouTube/Instagram) with 20k-300k followers.
- **Tier 2: Talent Agencies:** Boutique agencies managing multiple creators needing automated reporting.

## 3. Core Features (The Roadmap)
### A. Brand Deals CRM
Tracks the sponsorship lifecycle (Negotiation -> Contract -> Delivery -> Payment). Automates follow-ups for stalled deals via AI.
### B. Content Strategy Hub
Centralizes production schedules. Detects engagement spikes and suggests strategic content pivots based on real-time data.
### C. Live Media Kit
A dynamic, public URL (calibre.app/user) with real-time metrics and AI-generated insights to close brand deals faster.

## 4. AI Agent Architecture (The Brain)
The agent operates on a **Heartbeat Loop**:
1. **Observe:** Fetches data from YouTube, Instagram, and Gmail via MCP.
2. **Reason:** Compares current data with historical memory (Supabase).
3. **Plan:** Identifies business opportunities or administrative tasks.
4. **Act:** Executes tools (Drafts emails, updates Media Kits).
5. **Remember:** Persists outcomes to refine future strategies.

## 5. Tech Stack
- **Frontend:** React + Vite + Typescript + Tailwind CSS (Cinematic UI with GSAP).
- **Backend:** Node.js + Express + Supabase (PostgreSQL).
- **AI Core:** Gemini 2.0 Flash (Autonomous Function Calling).
- **Architecture:** Screaming Architecture (Domain-Driven Design).

## 6. Business Model (SaaS)
- **Creador ($12/mo):** Basic CRM + 1 Live Media Kit.
- **Pro ($29/mo):** Full AI Agent features + Automated Business Insights.
- **Estudio ($79/mo):** Agency dashboard + Multi-creator management.
